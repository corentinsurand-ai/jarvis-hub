# JARVIS — Hub public

Vitrine publique du poste de commandement de **Corentin Surand** (JARVIS — Just A Rather Very Intelligent System).

- `index.html` — hub HUD « Iron Man » publié sur GitHub Pages : systèmes publics avec stats GitHub en direct (API GitHub), décisions et projets (version publique).
- `data/memory-public.json` — snapshot public de la mémoire (aucune donnée privée).
- `.github/workflows/pages.yml` — publication auto à chaque push (nécessite Pages activé : Settings → Pages → Source « GitHub Actions »).

La **mémoire complète et privée** de Jarvis (profil, préférences, décisions sensibles, journal) vit sur le dépôt privé `corentinsurand-ai/jarvis`.
